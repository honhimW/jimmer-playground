### Version Mapping

> [!note]  
> Since Jimmer frequently introduces breaking changes (even in patch versions),
> it is not possible to make third‑party extensions compatible with all releases.
> 
> I will only develop against the version I personally use, and dependencies will be updated irregularly.

#### Jimmer 0.9.119

```groovy
implementation 'io.github.honhimw:jimmer-xxx:0.4.x'
```

#### Jimmer 0.9.113

```groovy
implementation 'io.github.honhimw:jimmer-ddl:0.3.x'
```
